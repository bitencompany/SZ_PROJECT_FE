# 이름결 — 사주·성명학 웹 서비스

프로젝트 기획서(`code_artifact.md`), 성명학 명세(`code_artifact (1).md`), 행동 강령(`ai.md`)을 기반으로 만든 Next.js App Router / TypeScript / Tailwind CSS 첫 버전입니다.

## 실행

```sh
npm install
cp .env.example .env.local
npm run dev
```

http://127.0.0.1:3000 에서 확인합니다. 키 없이 이름 입력 → 한자 선택 → 원형이정·발음오행 분석을 사용할 수 있습니다. ‘예시로 채우기’는 김서준(金書俊)을 선택합니다.

현재 실행 환경에서 Turbopack의 내부 포트 통신이 제한되어 개발·빌드 스크립트는 공식 지원 `--webpack` 옵션을 사용합니다.

## SAZU 연결

- 공식 계약: https://www.sazu.app/manse-api/docs#overview (2026-10-27 확인)
- `.env.local`의 `SAZU_API_KEY`에 키를 설정한 뒤 개발 서버를 재시작합니다. 키에 `NEXT_PUBLIC_` 접두사를 붙이지 마세요.
- 브라우저 → `/api/sazu` → `https://api.sazu.app/v2/sazu/manse` 순서로 호출합니다. 외부 키는 `server-only` 모듈에서만 사용합니다.
- 출생 정보 단계에서 날짜·시간(또는 미상)·성별·국내 도시를 입력하고 정보 제공에 동의합니다. 결과 화면의 ‘사주 불러오기’를 눌러야 전송됩니다. 이름은 SAZU에 보내지 않습니다.
- 무료 키는 고정 샘플만 지원합니다. ‘SAZU 샘플 입력’으로 1998-05-19 10:00 / 남성 / 서울을 입력할 수 있습니다. 응답 `meta.sample`이 참이면 화면에 샘플임을 명시합니다.
- 첫 버전은 **양력**만 지원합니다. 음력/윤달·해외 출생은 아직 지원하지 않습니다. 시각 미상은 시·분 `null`을 보내고 시주 없음으로 표시합니다.
- 키 미설정, 샘플 제한, 호출 제한, 타임아웃, 잘못된 응답은 한국어 오류로 처리합니다. 외부 오류 본문·키·개인정보를 로그에 출력하지 않습니다.
- **실제 키로 호출 검증은 아직 하지 않았습니다.** 공식 문서 기반 요청·응답 어댑터와 계약 테스트를 구현한 상태입니다.
- 결제 승인·사용자 인증·지속형 호출 제한 도입 전에는 `NODE_ENV=production`에서 SAZU 호출을 차단합니다. 현재 개발용 로컬 서버에서만 연결을 시험할 수 있습니다. 운영 게이트는 결제 권한 검증으로 교체해야 합니다.

## 구현 범위와 데이터 상태

- 성 1자 + 이름 2자의 한글 이름을 지원합니다. 한자 선택은 네이티브 모달(키보드 포커스/ESC 지원)로 구현했습니다.
- `src/data/hanja.ts`는 **UI 검증용 예시 데이터**이며 전체 대법원 인명용 한자 DB가 아닙니다. 원획수도 상용 서비스 전 별도 출처 검수가 필요합니다. 없는 한자를 임의로 대체하지 않습니다.
- `src/data/suri_81.json`은 사용자 제공 `81.md`를 그대로 옮겼습니다. 원형이정은 서버가 선택된 한자의 획수를 조회해 계산합니다. 클라이언트가 보내는 획수는 사용하지 않습니다.
- 81 초과 수는 80씩 차감합니다(81→81, 82→2, 161→81). 된소리는 명세에 없으므로 미분류로 표시합니다. 발음오행은 이름 순서의 정방향/역방향 관계를 구분합니다.
- 원문에서 玉의 자원오행이 토·금으로 중복되고 불용문자 목록이 없어 `element`와 `isBulyong`은 미확정입니다. 자원오행 보완·불용문자 판정은 보류합니다. 원획수 DB와 오행 개수만으로 용신을 추정하지 않습니다.
- 풀이 문장은 제공된 81수리 자료입니다. **AI 생성 해설·NICE 결제·DB 저장은 아직 구현하지 않았습니다.**
- 입력 정보는 브라우저 상태와 요청 처리 중에만 사용합니다. 새로고침하면 초기화되며 애플리케이션에서 로컬 저장소나 DB에 저장하지 않습니다. 상용 개인정보 정책과 외부 업체 보관 정책은 출시 전에 확정해야 합니다.
